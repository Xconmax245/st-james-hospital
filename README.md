# NYU Langone Health | Tisch Hospital Portal

This is the official patient transparency and institutional marketing portal for **NYU Langone Tisch Hospital**.

## Key Features
- **CareView Dashboard**: Secure, real-time clinical monitoring for patients.
- **Institutional Marketing**: High-fidelity pages for About, Services, Research, and Careers.
- **Responsive Navigation**: Full-screen mobile experience with institutional branding.
- **Admin Console**: Secure registry management for clinical staff.

## Getting Started

First, install dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Technology Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion & AOS (Animate on Scroll)
- **Icons**: Lucide React

## Deployment
Deployed on Vercel with automated CI/CD via GitHub.
